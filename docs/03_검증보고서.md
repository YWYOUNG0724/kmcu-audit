## 검증 중 발견·수정한 문제
1. **부서 매핑 과다** — 기획처 키워드 "규정"이 관련규정 열("인사규정" 등)까지 매칭해 37건 표시 → 키워드는 지적내용에서만 찾도록 수정 → 19건.
2. **챗봇 오타 보정 과잉** — "준비→교비", "통계→회계", "문제→과제"처럼 2글자 단어가 엉뚱하게 바뀜 → 2글자는 보정하지 않고, 4글자 이하는 1글자 차이만 허용.
3. **금액 순위 질문** — "금액이 가장 많은 분야"에 건수 순위로 답함 → 금액 질문이면 금액 순위로 답하도록 수정.
4. **모바일 표** — 기관명이 한 글자씩 줄바꿈 → 760px 이하에서 카드형 목록으로 전환.
5. **KPI 배치** — 5개 카드가 3열에서 빈칸 생김 → 화면 폭에 맞춰 자동 배치.

## 남은 제약 (확인하지 못한 것)
- Claude 앱 내장 브라우저는 서비스워커 등록을 막아 "앱 설치"는 그 창에서 확인할 수 없음 (일반 Chrome에서는 정상 확인).
- iOS Safari, 삼성 인터넷에서의 설치 동작은 시험하지 않음.
- 실제 교육부 감사 데이터로는 시험하지 않음 (가상 예시 데이터와 양식 CSV로만 검증).
