# MVP 정의 — KMCU Audit Board v1.0

## 1. MVP 한 줄 정의
"다른 대학 감사 지적사례를 불러와 **통계·검색·부서별 점검**을 오프라인으로 할 수 있는 설치형 웹앱"

## 2. 포함 기능 (Must)
| # | 화면 | 완료 기준 |
|---|---|---|
| 1 | 대시보드 | KPI 5개와 차트 6개가 현재 데이터로 계산되어 표시됨 |
| 2 | 사례목록 | 검색어·3종 필터·정렬·20건 단위 페이지, 행 클릭 시 상세 모달 |
| 3 | 기관별 | 기관 검색, 건수/금액 정렬, 선택 시 사례 목록 |
| 4 | 준비가이드 | 분야 10개, 점검표 체크 상태가 새로고침 후에도 유지, 진행률 표시 |
| 5 | 담당업무 | 부서 9개 카드, 선택 시 관련 사례 표시 |
| 6 | AI 도우미 | 질문 → 의도(통계/가이드/사례 검색) 판단 → 답변 + 관련 사례 최대 5건, 오타 1~2자 허용 |
| 7 | 데이터 관리 | CSV/JSON 불러오기, JSON 내보내기, 예시 데이터 복원 |
| 8 | PWA | manifest + 서비스워커, 오프라인 재실행 가능 |

## 3. 제외 (Won't, 이번 버전)
로그인, 서버 저장, 생성형 AI, PDF 원문 뷰어.

## 4. 기술 구성
```
KMCU_AUDIT/
├─ index.html          화면 골격(탭 6개 + 데이터 관리 모달)
├─ css/styles.css      테마 토큰, 반응형
├─ js/app.js           데이터 로드·대시보드·목록·기관·부서·데이터 관리
├─ js/guide.js         준비가이드 내용과 점검표
├─ js/chatbot.js       로컬 검색형 챗봇
├─ data/sample-cases.json   가상 예시 데이터
├─ data/departments.json    계명문화대 부서 ↔ 지적유형/키워드 매핑
├─ data/import-template.csv 불러오기 양식
├─ manifest.json, sw.js, icons/
└─ docs/ (분석결과, PRD, MVP, 검증보고서)
```

## 5. 검증 계획
| 항목 | 방법 |
|---|---|
| 화면 렌더링 | 로컬 서버로 실행 후 브라우저에서 6개 탭 확인, 콘솔 오류 0건 |
| 계산 정확성 | 예시 데이터의 합계를 별도 스크립트로 계산해 KPI와 대조 |
| 검색/필터 | 키워드·필터 조합 결과 건수 확인 |
| 데이터 불러오기 | 템플릿 CSV 불러오기 → 건수 반영 확인 |
| 점검표 저장 | 체크 → 새로고침 → 유지 확인 |
| 챗봇 | 오타 포함 질문, 통계 질문, 가이드 질문 응답 확인 |
| PWA | manifest·서비스워커 등록 확인 |
| 모바일 | 375px 폭에서 가로 스크롤 없음 |
