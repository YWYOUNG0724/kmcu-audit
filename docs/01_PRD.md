# PRD — 계명문화대학교 감사 대비 지적사례 현황판 (KMCU Audit Board)

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.0 (2026-11-09) |
| 대상 기관 | 계명문화대학교 (전문대학) |
| 주 사용자 | 감사 담당 부서, 각 부서 업무 담당자, 보직자 |
| 형태 | 설치형 웹앱(PWA) — PC 브라우저 + 모바일 홈 화면 설치 |

## 1. 배경과 목적
교육부·관계기관 감사에서 다른 대학이 받은 지적사례는 우리 대학의 사전 점검 자료로 매우 유용하지만, 원문(PDF)이 흩어져 있어 부서별로 찾아보기 어렵다.
이 앱은 공개된 감사 지적사례를 **한 화면에서 통계로 보고, 검색하고, 우리 부서 업무와 연결해** 감사 전에 스스로 점검할 수 있게 한다.

## 2. 목표 / 성공 지표
| 목표 | 지표 |
|---|---|
| 지적사례를 빠르게 찾는다 | 키워드 검색 후 원하는 사례 확인까지 30초 이내 |
| 부서가 자기 업무 관련 사례를 본다 | 부서 탭에서 1클릭으로 관련 사례 목록 |
| 감사 준비를 체계화한다 | 분야별 점검표 체크 진행률 저장·확인 |
| 별도 서버 없이 운영한다 | 정적 호스팅(학내 웹서버, GitHub Pages)만으로 배포 |

## 3. 사용자와 시나리오
1. **감사 담당자**: 새로 공개된 감사결과를 CSV로 정리해 앱에 불러오고, 대시보드로 경향(많이 지적되는 분야, 금액)을 보고서에 활용한다.
2. **부서 담당자(예: 재무)**: "담당업무" 탭에서 자기 부서를 눌러 관련 지적사례를 보고, "준비가이드"의 점검표를 체크한다.
3. **보직자**: 모바일에서 홈 화면 아이콘으로 열어 KPI와 상위 지적 유형을 확인한다.
4. **누구나**: "AI 도우미"에 "연구비 부정 사용 사례"처럼 질문하면 관련 사례를 찾아 준다.

## 4. 기능 요구사항
| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 대시보드 | KPI 5종(사례 수, 부당집행금액, 기관 수, 관련자 수, 금액 발생 건) + 차트 6종 | 필수 |
| F2 | 사례목록 | 키워드 검색, 지적유형/감사종류/처분 필터, 열 정렬, 페이지 이동, 상세 보기 | 필수 |
| F3 | 기관별 | 기관 검색·목록(건수·금액), 기관 선택 시 해당 사례와 유형 분포 | 필수 |
| F4 | 준비가이드 | 분야별 위험도, 주요 점검사항(체크박스, 진행률 저장), 준비서류, 필수 확인사항 | 필수 |
| F5 | 담당업무 | 계명문화대 부서별로 관련 지적유형·키워드를 매핑해 사례 표시 (매핑은 설정 파일로 수정) | 필수 |
| F6 | AI 도우미 | 서버 없이 동작하는 로컬 검색형 챗봇(오타 허용, 동의어 확장, 의도 분류: 통계/사례/가이드) | 필수 |
| F7 | 데이터 관리 | CSV/JSON 불러오기, 현재 데이터 JSON 내보내기, 예시 데이터로 초기화 | 필수 |
| F8 | PWA | 설치, 오프라인 실행(서비스워커 캐시), PC/모바일 화면 대응 | 필수 |
| F9 | 다크/라이트 테마 | 시스템 설정 따름 + 수동 전환 | 선택 |
| F10 | 생성형 AI 연동 | 학내 프록시를 통한 Claude API 답변 | 차기 |
| F11 | 원문 PDF 연결 | 사례별 원문 링크(URL 필드) 열기 | 차기 |

## 5. 데이터 모델
```json
{
  "id": "C0001",
  "institution": "기관명",
  "auditType": "종합감사 | 회계감사 | 특정감사 | 사안감사 | 기타",
  "category": "예산·회계 | 채용·인사 | 교육·학사 | 연구비·과제 | 시설·공사 | 계약·입찰 | 복무·겸직 | 징계·법령 | 개인정보·공시 | 학생·장학 | 기타",
  "issue": "지적 내용",
  "law": "관련 규정",
  "action": "처분 (예: 경고, 주의, 시정 — 쉼표로 여러 개)",
  "amount": 0,
  "persons": 0,
  "year": 2025,
  "url": "원문 링크(선택)"
}
```
- `amount` 단위: 천원. 화면에는 억원/만원으로 자동 변환.
- CSV는 영문 필드명 또는 한글 열 이름(기관명, 감사종류, 지적유형, 지적내용, 관련규정, 처분, 금액, 관련자, 연도, 링크)을 모두 인식.

## 6. 비기능 요구사항
- 서버·DB 없음, 정적 파일만. 외부 의존성은 Chart.js(cdnjs, 버전 고정) 하나.
- 오프라인 동작: 첫 방문 후 서비스워커 캐시로 실행.
- 반응형: 360px 폭 휴대폰부터 PC까지, 가로 스크롤 없음.
- 접근성: 버튼·입력에 레이블, 키보드로 탭 이동 가능, 색만으로 정보 전달하지 않음.
- 개인정보: 사례 데이터에 개인 실명을 넣지 않음. 불러온 데이터는 사용자 브라우저(localStorage)에만 저장.

## 7. 저작권·데이터 원칙
- 참고 사이트의 화면 구성은 참고했으나 코드·문구·데이터는 새로 작성.
- 실제 운영 데이터는 교육부 등 공개 감사결과 원문에서 감사실이 직접 정리해 불러온다.
- 기본 탑재 데이터는 **가상의 예시**이며 화면에 "예시 데이터" 표시를 한다.

## 8. 범위 밖 (이번 버전)
