## 2. 처리 절차 (`tools/`)
| 단계 | 스크립트 | 내용 |
|---|---|---|
| 1 | `01_list_moe_board.py` | 게시판 목록 1,002건 수집 → `raw/board_list.json` |
| 2 | `02_download_reports.py` | 대상 글의 첨부파일 다운로드, 크기·SHA-256 기록 → `raw/reports/manifest.json` |
| 3 | `03_extract_findings.py` | 보고서에서 지적사항 추출 → `data/moe-cases.json` |
| 4 | `04_validate.py` | 공식 건수 대조·항목 점검 → `raw/validation.json` |
| 5 | `05_school_types.py` | 학교 종류(전문대학 등) 분류 → `data/school-types.json`, 각 건에 `schoolType` 추가 |
| 보조 | `hwp_text.py` | HWP(5.x)·HWPX 텍스트 추출기 (외부 프로그램 없이 동작) |

보고서 형식이 연도별로 달라 세 가지 파서를 순서대로 적용합니다.
- **2024~ 처분서 형식**: "제 목 / 소관기관 / 관계법령 / 조치할 사항"
- **2019~2023 표 형식**: "감사결과 처분서 — 연번 | 지적사항 | 처분"
- **2019 목록 형식**: "지적건명 | 지적내용 | 처분(안)" (회계부분감사 등)

검증 중 고친 주요 문제:
1. 처분 줄이 두 줄로 나뉘면 지적사항을 놓침
2. 첨부 표의 번호를 지적사항 번호로 오인
3. 본문 속 숫자("15명")를 번호로 오인해 이후 번호가 모두 밀림
4. "4대 폭력"처럼 숫자로 시작하는 제목을 버림
5. 괄호 없이 쓴 법령명 누락
6. '회계부분감사' 감사종류 미인식

## 6. 필드 정의와 해석상 주의
| 필드 | 설명 |
|---|---|
| institution | 감사 대상 대학(게시글 제목 기준) |
| org | 처분서의 소관기관(학교법인 포함) |
| category | 제목·내용 키워드로 자동 분류한 지적유형 (규칙: `CATEGORY_RULES`) |
| action | 처분 종류(경고·주의·시정·통보·징계 등). 교육부 등의 '별도조치'는 제외 |
| amount | 처분 내용 중 회수·징수·세입 요구 금액의 최댓값(천원). 보고서 총괄표의 '회수' 합계와 다를 수 있음 |
| persons | 처분 대상 인원(괄호 안 'n명' 합계 또는 관련자 기호 수) — **추정값** |
| detail | 감사결과 확인된 문제점 앞부분(최대 400자) |
| schoolType | 학교 종류: 전문대학·일반대학·교육대학·원격·사이버대학·대학원대학·기타기관 |
| url | 교육부 원문 게시글 링크 |

- 자동 추출 자료이므로 보고서·공문에 인용할 때는 반드시 원문 링크로 확인하세요.
- 분류(category)는 키워드 규칙에 따른 것으로, 사람이 판단한 분류와 다를 수 있습니다.

## 7. 다시 만들기 / 갱신
```bash
python -X utf8 tools/01_list_moe_board.py raw/board_list.json
python -X utf8 tools/02_download_reports.py 2019
python -X utf8 tools/03_extract_findings.py data/moe-cases.json
python -X utf8 tools/04_validate.py
python -X utf8 tools/05_school_types.py   # 전문대학 명단을 새로 받으려면 --refresh
```
갱신 후에는 `sw.js`의 `CACHE` 버전을 올려야 설치된 앱에도 반영됩니다. 배포할 때 `raw/`(약 200MB)와 `tools/`는 올리지 않아도 됩니다.
